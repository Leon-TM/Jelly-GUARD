# Jolly Guard - Smart Jellyfish Alert System

🌐 **Live Demo:** https://leon-tm.github.io/Jelly-GUARD

## About This Project

Jolly Guard is an innovative early warning system developed for the Blue-Cloud Hackathon 2025 that combines satellite data, oceanographic models, and machine learning to predict jellyfish blooms and enhance marine safety.

## 🚀 Demo Tecnica

Il sistema del prototipo robotico "Jelly Fish Robot" mostra come integrare avvistamenti di meduse con dati ambientali (temperatura superficiale, clorofilla, correnti superficiali) per generare un **rischio geolocalizzato** visualizzato su mappa.
